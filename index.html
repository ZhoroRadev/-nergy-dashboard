Зареждане на данни от CSV

Данните остават локално в браузъра и не се изпращат до сървър. Не качвай поверителни данни в публично GitHub хранилище.

CSV колони: timestamp, dam_eur_mwh, intraday_eur_mwh, balancing_eur_mwh. Допускат се празни стойности за отделни ценови серии.

Автоматично обновяване

GitHub Actions стартира колектор за публичния JSON на ЕСО. Файлът data/eso.json се обновява при успешно извличане. Неуспешно извличане запазва предишните данни и отчита грешка.

Препоръчителен подход за БНЕБ: лицензиран API или експортиране към CSV, без заобикаляне на ограниченията на източника.
