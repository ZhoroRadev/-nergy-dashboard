# Energy Trading Intelligence — Bulgaria

Готово статично интерактивно табло за **БНЕБ, ЕСО, метеопрогнози и BESS**. Работи на GitHub Pages. Интерфейсът е на български.

## Какво е реално свързано

| Данни | Статус |
|---|---|
| Прогноза за GHI, вятър, облачност и температура в 6 точки | API на Open-Meteo, директно от браузъра; изисква интернет |
| ЕСО — товар | Python колектор за публичен endpoint, GitHub Actions на 30 мин.; **може да изисква адаптиране към реалния JSON формат**; ако не разпознае данни, не публикува числа |
| БНЕБ — DAM / Intraday | CSV импорт; **няма автоматично свързан API** |
| Балансиращи цени | CSV импорт; **няма автоматично свързан API** |
| БESS | Локално опростено сравнение на две ценови точки; не е производствен оптимизатор |

**Не се показват фиктивни пазарни стойности като актуални.** Без реален CSV цените са празни.

## Публикуване на GitHub Pages

1. Създай GitHub repository с име `energy-dashboard` (може да е public). Не качвай фирмени тайни в публично repository.
2. Качи **всички файлове и папки** в главната директория, включително скритата папка `.github/workflows/`.
3. Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` → Save.
4. Сайтът става `https://ТВОЯ-USERNAME.github.io/energy-dashboard/`.
5. В Actions → `Collect ESO public data` → Run workflow може да пуснеш колектора ръчно. Плановото изпълнение е на всеки 30 минути, но GitHub Actions може да има закъснения или прекъсвания. При непозната структура на API, workflow ще отчете грешка и няма да подменя данните.
6. За публикуване на данни от workflow, в Settings → Actions → General → Workflow permissions включи `Read and write permissions`, ако е необходимо и разрешено.

## Локално стартиране

От папката на проекта:

```bash
python -m http.server 8000
```

Отвори `http://localhost:8000`. Метео данните изискват интернет. В някои браузъри `file://` може да ограничи `fetch()` към JSON, затова локалният HTTP сървър е предпочитан.

## Пазарен CSV

Заглавен ред:

```csv
timestamp,dam_eur_mwh,intraday_eur_mwh,balancing_eur_mwh
2026-11-05 12:00,100.4,102.2,99.0
2026-11-05 13:00,110.7,112.9,108.0
```

Това са **примерни числа само за документация**, не цени от борсата. Разделител `,` или `;`. Десетичен разделител `.`. Допускат се празни полета за отделните серии. Часовете в CSV се приемат за локални, без автоматична конверсия на часови зони. За точен DST анализ добави нормализация на времето при импорта. Данните в CSV се обработват само в браузъра.

## Ограничения

- Сайтът е публичен при публичен GitHub Pages репозиторий. Никога не публикувай лицензионни ключове, търговски позиции, клиентски данни или поверителни договори.
- Open-Meteo **безплатният API е за нетърговска употреба**. При фирмена употреба осигури подходящо лицензиране или смени доставчика с договорен Meteomatics API. Източник: https://open-meteo.com/en/pricing
- Графиките изискват Chart.js от jsDelivr. За напълно офлайн среда може да се приложи локален пакет.
- ESO JSON `https://www.eso.bg/api/last24load.json.php` може да промени формата си; схемата в `scripts/collect_eso.py` е умишлено консервативна, за да не представи грешни данни.
- За реална ФЕЦ/ВяЕЦ прогноза са необходими геопозиции на централите, инсталирана мощност, спецификации и исторически измервания.
- BESS арбитражът използва максимум една 1-часова двойка заряд-разряд в един ден, заряд ограничен от MW и MWh, идеализиран фиксиран КПД; не включва разходи, SOC, ограничения за мощност при различни температури и други пазарни продукти.
